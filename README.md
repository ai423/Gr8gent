# Gr8gent

פלטפורמה שבה נותנים מטרה, מקבלים צוות סוכנים, ורואים, מדברים ושולטים בכל מה שהוא עושה.
האפיון המלא ב-[SPEC.md](SPEC.md), והוא מקור האמת של המוצר.

## מצב נוכחי

M0 (ליבה): `packages/core` מכיל את הטיפוסים, מנוע ה-Policy, ה-Action Gateway וה-Ledger, עם בדיקות.

```bash
npm install
npm test
npm run typecheck
```
